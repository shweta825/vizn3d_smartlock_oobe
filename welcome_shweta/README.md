# Welcome Shweta Demo

This folder is isolated from the original NXP Smart Lock source tree.

Purpose:
- Detect the registered face name supplied by the existing face-recognition result.
- Show "Welcome Shweta" when the recognized name is exactly "Shweta".
- Keep the original NXP source files unchanged.

Integration is intentionally left to the project owner. This demo does not modify the original Smart Lock UI implementation.
